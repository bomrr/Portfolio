# Portfolio

A collection of coursework and projects I considered worthy of showing to others.

## Contents
- 3D Graphics - Java OpenGL assignments, each made using Java to run through the graphics pipeline. Each renders a different scene, complete with controls.
- Databases - SQL assignment scripts and screenshots.
- DataStructures - Java implementations of a binary tree, a list, a queue, and a stack.
- ObjOrientedGraphics - Codename One mobile/desktop projects. Each project is a continuation of the previous.
- OperatingSystems - Contains two C programs that hash inputted files, with a detailed writeup included.

## Quick start (Windows)
- Java projects: open in IDE or
  - cd to project folder, compile: javac *.java
  - run: java Main
- 3DGraphics: run the provided compile.bat / run.bat in each A# folder.
- C programs (OperatingSystems): compile with gcc, e.g.:
  - gcc -o sharedhash sharedhash.c esharedhash.c
- SQL scripts: open the files in the Assignment folders and run in your SQL client.
